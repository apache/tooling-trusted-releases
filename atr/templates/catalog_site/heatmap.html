How to read this report

Health (0–1) averages release recency, shared workload, active maintainers and project guidance using A-O's formula. Maintained (0–10) is OpenSSF Scorecard's check of commits and issue activity over 90 days. We show both because an active project can still rely on one person.

Criticality (0–1) estimates importance from ecosyste.ms popularity rankings: downloads, dependents, stars and forks.

Risk (0–1) is criticality × (1 − health). It highlights important packages with poor health.

Missing data stays unknown. Archived projects get Health 0.05. Advisories are separate from these scores.
